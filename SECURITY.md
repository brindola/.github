# Security policy

Brindola runs the till, the kitchen and the cash drawer in working venues, so we take every security report seriously and we thank everyone who sends one.

## Reporting a vulnerability

Email **[security@brindola.com](mailto:security@brindola.com)**. Please do not report security issues in public discussions, issues or social media.

A good report includes:

- the product and version (Brindola POS on Windows, Linux or Android, the Brindola app, brindola.com, or the Brindola account site);
- what an attacker could do, and the steps to reproduce it;
- any proof-of-concept, logs or screenshots, with **no real venue, customer or payment data in them**.

We confirm every report we receive, keep you informed while we work on it, and tell you when the fix ships. If you would like to be credited, tell us the name to use.

## Supported versions

Security fixes go into the current release. Please test against the latest version from [brindola.com/en/download](https://brindola.com/en/download/).
